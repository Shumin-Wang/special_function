高斯积分的常见性质及完整证明

一、标准高斯积分

性质：

\[ \int_{-\infty}^{+\infty} e^{-x^2}\,\mathrm{d}x = \sqrt{\pi} \]

证明：

记积分为 \(I\)，则有：

\[ I^2 = \left(\int_{-\infty}^{+\infty} e^{-x^2}\,\mathrm{d}x\right)^2 = \int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} e^{-(x^2+y^2)}\,\mathrm{d}x\,\mathrm{d}y \]

利用极坐标变换 \(x=r\cos\theta,\,y=r\sin\theta\)，\(\mathrm{d}x\mathrm{d}y=r\,\mathrm{d}r\mathrm{d}\theta\)，得：

\[ I^2=\int_{\theta=0}^{2\pi}\int_{r=0}^{+\infty} e^{-r^2}r\,\mathrm{d}r\,\mathrm{d}\theta \]

分别积分：

\[ =\left(\int_{0}^{2\pi}\mathrm{d}\theta\right)\left(\int_{0}^{+\infty} re^{-r^2}\,\mathrm{d}r\right)=2\pi\cdot\frac{1}{2}=\pi \]

因此：

\[ I=\sqrt{\pi} \]

二、一般形式高斯积分

性质（\(a>0\)）：

\[ \int_{-\infty}^{+\infty} e^{-ax^2}\,\mathrm{d}x = \sqrt{\frac{\pi}{a}} \]

证明：

令 \(u=\sqrt{a}\,x\)，则 \(x=\frac{u}{\sqrt{a}}\)，\(\mathrm{d}x=\frac{\mathrm{d}u}{\sqrt{a}}\)，于是：

\[ \int_{-\infty}^{+\infty} e^{-ax^2}\,\mathrm{d}x =\frac{1}{\sqrt{a}}\int_{-\infty}^{+\infty} e^{-u^2}\,\mathrm{d}u =\sqrt{\frac{\pi}{a}} \]

三、奇次幂高斯积分

性质（\(n\)为奇数，\(a>0\)）：

\[ \int_{-\infty}^{+\infty} x^n e^{-ax^2}\,\mathrm{d}x = 0 \]

证明：

当\(n\)为奇数时，被积函数\(f(x)=x^n e^{-ax^2}\)为奇函数（满足\(f(-x)=-f(x)\)），对称区间积分为零。

四、偶次幂高斯积分

性质（\(n=2k\)，\(k=0,1,2,\dots\)）：

\[ \int_{-\infty}^{+\infty} x^{2k} e^{-ax^2}\,\mathrm{d}x=\frac{(2k-1)!!}{2^k a^k}\sqrt{\frac{\pi}{a}} \]

特别地，递推公式为：

\[ \int_{-\infty}^{+\infty} x^{2k} e^{-ax^2}\,\mathrm{d}x=-\frac{\mathrm{d}}{\mathrm{d}a}\int_{-\infty}^{+\infty} x^{2k-2} e^{-ax^2}\,\mathrm{d}x \]

偶次幂高斯积分的完整证明过程

我们考虑如下积分（其中 \(a>0\)，整数 \(k\geq 0\)）：

\[ \int_{-\infty}^{+\infty} x^{2k} e^{-a x^2}\,\mathrm{d}x \]
步骤一：基本积分及递推关系

首先回顾标准高斯积分的结果：

\[ \int_{-\infty}^{+\infty} e^{-a x^2}\,\mathrm{d}x = \sqrt{\frac{\pi}{a}} \]

注意到：

\[ \frac{\mathrm{d}}{\mathrm{d}a}\left(e^{-a x^2}\right) = -x^2 e^{-a x^2} \]

由此建立递推关系：

\[ \int_{-\infty}^{+\infty} x^2 e^{-a x^2}\,\mathrm{d}x = -\frac{\mathrm{d}}{\mathrm{d}a}\int_{-\infty}^{+\infty} e^{-a x^2}\,\mathrm{d}x = -\frac{\mathrm{d}}{\mathrm{d}a}\left(\sqrt{\frac{\pi}{a}}\right) \]
步骤二：以 \(k=1\) 为例详细计算

对上式求导，得：

\[ -\frac{\mathrm{d}}{\mathrm{d}a}\left(\sqrt{\frac{\pi}{a}}\right) = -\frac{\mathrm{d}}{\mathrm{d}a}\left(\pi^{1/2}a^{-1/2}\right) = -\sqrt{\pi}\left(-\frac{1}{2}\right)a^{-3/2} = \frac{\sqrt{\pi}}{2a^{3/2}} \]

即：

\[ \int_{-\infty}^{+\infty} x^2 e^{-a x^2}\,\mathrm{d}x = \frac{\sqrt{\pi}}{2a^{3/2}} \]
步骤三：一般递推公式

对于一般情况 \(k \geq 1\)，递推关系如下：

\[ \int_{-\infty}^{+\infty} x^{2k} e^{-a x^2}\,\mathrm{d}x = -\frac{\mathrm{d}}{\mathrm{d}a}\int_{-\infty}^{+\infty} x^{2k-2} e^{-a x^2}\,\mathrm{d}x \]

以此逐步计算，得到：

  • 当 \(k=2\) 时：
\[ \int_{-\infty}^{+\infty} x^4 e^{-a x^2}\,\mathrm{d}x = -\frac{\mathrm{d}}{\mathrm{d}a}\left(\frac{\sqrt{\pi}}{2a^{3/2}}\right) = \frac{3\sqrt{\pi}}{4a^{5/2}} \]
  • 当 \(k=3\) 时：
\[ \int_{-\infty}^{+\infty} x^6 e^{-a x^2}\,\mathrm{d}x = -\frac{\mathrm{d}}{\mathrm{d}a}\left(\frac{3\sqrt{\pi}}{4a^{5/2}}\right) = \frac{15\sqrt{\pi}}{8a^{7/2}} \]
步骤四：总结一般公式（双阶乘形式）

根据上述递推过程，一般形式可表示为：

\[ \int_{-\infty}^{+\infty} x^{2k} e^{-a x^2}\,\mathrm{d}x = \frac{(2k-1)!!}{2^k a^k}\sqrt{\frac{\pi}{a}} \]

其中，双阶乘定义为：

\[ (2k-1)!! = (2k-1)(2k-3)\cdots 5\cdot3\cdot1 \]

例如：

  • \(1!! = 1\)
  • \(3!! = 3\times1 = 3\)
  • \(5!! = 5\times3\times1 = 15\)

最终公式总结：

\[ \boxed{ \int_{-\infty}^{+\infty} x^{2k} e^{-a x^2}\,\mathrm{d}x = \frac{(2k-1)!!}{2^k a^k}\sqrt{\frac{\pi}{a}},\quad a>0,\,k\geq0 } \]

五、多维高斯积分

设\(n\)维正定对称矩阵\(A\)，则：

\[ \int_{\mathbb{R}^n} e^{-\mathbf{x}^\top A \mathbf{x}}\,\mathrm{d}\mathbf{x}=\frac{\pi^{n/2}}{\sqrt{\det(A)}} \]

多维高斯积分的详细证明

我们要证明的积分公式如下：

\[ \int_{\mathbb{R}^n} e^{-\mathbf{x}^{\top} A \mathbf{x}}\,\mathrm{d}\mathbf{x} = \frac{\pi^{n/2}}{\sqrt{\det(A)}},\quad A\text{为正定对称矩阵} \]
步骤一：积分定义

设积分为：

\[ I = \int_{\mathbb{R}^n} e^{-\mathbf{x}^{\top} A \mathbf{x}}\,\mathrm{d}\mathbf{x}, \]

其中\(\mathbf{x}\in\mathbb{R}^n\)，\(A\) 为\(n\times n\)的正定对称矩阵。

步骤二：特征分解

因为矩阵\(A\)为实对称正定矩阵，因此可作特征分解：

\[ A = Q\Lambda Q^{\top}, \]
  • 其中\(Q\)是正交矩阵，即满足\(Q^{\top}Q=I\)；
  • \(\Lambda=\mathrm{diag}(\lambda_1,\dots,\lambda_n)\)，\(\lambda_i>0\)为\(A\)的特征值。

于是积分化为：

\[ I=\int_{\mathbb{R}^n} e^{-\mathbf{x}^{\top} Q\Lambda Q^{\top}\mathbf{x}}\,\mathrm{d}\mathbf{x}. \]
步骤三：变量替换

令\(\mathbf{y}=Q^{\top}\mathbf{x}\)，则有：

  • \(\mathbf{x}=Q\mathbf{y}\)；
  • 由于\(Q\)为正交矩阵，\(\mathrm{d}\mathbf{x}=\mathrm{d}\mathbf{y}\)。

积分变为：

\[ I=\int_{\mathbb{R}^n} e^{-(Q\mathbf{y})^{\top}Q\Lambda Q^{\top}(Q\mathbf{y})}\,\mathrm{d}\mathbf{y}. \]

由于正交性，\(Q^{\top}Q=I\)，因此积分简化为：

\[ I=\int_{\mathbb{R}^n} e^{-\mathbf{y}^{\top}\Lambda\mathbf{y}}\,\mathrm{d}\mathbf{y}. \]
步骤四：积分的分解与计算

由于\(\Lambda\)为对角矩阵，上式可进一步分解为一维积分的乘积：

\[ I=\prod_{i=1}^{n}\int_{-\infty}^{+\infty} e^{-\lambda_i y_i^2}\,\mathrm{d}y_i. \]

对每个积分分别计算，利用标准高斯积分结果：

\[ \int_{-\infty}^{+\infty} e^{-\lambda_i y_i^2}\,\mathrm{d}y_i=\sqrt{\frac{\pi}{\lambda_i}}. \]

因此得到：

\[ I=\prod_{i=1}^{n}\sqrt{\frac{\pi}{\lambda_i}}. \]
步骤五：特征值与行列式的关系

特征值的乘积等于矩阵的行列式：

\[ \det(A)=\det(Q\Lambda Q^{\top})=\det(\Lambda)=\lambda_1\lambda_2\cdots\lambda_n. \]

于是，我们最终得到积分结果：

\[ I=\frac{\pi^{n/2}}{\sqrt{\lambda_1\lambda_2\cdots\lambda_n}}=\frac{\pi^{n/2}}{\sqrt{\det(A)}}. \]
最终结论

综上所述，完整证明了多维高斯积分公式：

\[ \boxed{ \int_{\mathbb{R}^n} e^{-\mathbf{x}^{\top} A \mathbf{x}}\,\mathrm{d}\mathbf{x}=\frac{\pi^{n/2}}{\sqrt{\det(A)}},\quad A>0 } \]
